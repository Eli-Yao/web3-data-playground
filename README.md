# Web3 Data Playground ⚡

> Web3 数据分析学习仓库 — Dune Analytics、链上数据查询、实习准备

## 📁 目录结构

```
.
├── dune-queries/          # Dune Analytics SQL 查询
│   ├── ethereum/          # 以太坊核心数据
│   ├── defi/              # DeFi 协议分析
│   ├── nft/               # NFT 市场分析
│   └── layer2/            # L2 扩容方案
├── notes/                 # 学习笔记
├── datasets/              # 数据集参考
└── dashboards/            # Dashboard 构思 & 链接
```

## 🚀 快速开始

1. 前往 [Dune Analytics](https://dune.com) 注册账号
2. 在 Dune 上打开 Query Editor
3. 从 `dune-queries/` 中选择查询，复制粘贴运行

## 📚 学习路线

- Dune SQL 基础语法
- 区块链数据模型 (Ethereum)
- DeFi 协议数据分析
- NFT 市场数据分析
- Dashboard 可视化最佳实践
