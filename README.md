## 📁 项目结构

```
dune-queries/       ← Dune Analytics SQL 查询
├── ethereum/       ← 以太坊核心数据（区块、交易）
├── defi/           ← DeFi 协议分析
├── nft/            ← NFT 市场分析
└── layer2/         ← L2 扩容方案对比

notes/              ← 学习笔记 & 知识点总结
datasets/           ← 常用数据集参考（Dune 表结构）
dashboards/         ← Dashboard 构思 & 公开链接
```

---

## 🚀 快速开始

```bash
git clone https://github.com/Eli-Yao/web3-data-playground.git
cd web3-data-playground
```

1. 前往 [Dune Analytics](https://dune.com) 注册
2. 打开 Query Editor
3. 从 `dune-queries/` 选一个查询复制进去运行
